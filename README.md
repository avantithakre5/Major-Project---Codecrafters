# Major-Project---Codecrafters
Web based platform for recommending courses and Practicing quizes for training professionals.
A PHP-based web application designed to assess user skills through interactive quizzes and recommend suitable learning paths and technologies based on rule-based logic and user performance.

🚀 Key Features

User authentication and personalized dashboards

Technology selection and skill assessment via MCQ-based quizzes

Score-based proficiency classification (Beginner, Intermediate, Advanced)

Dynamic learning resource recommendations

Course categorization and sorting system

Progressive multi-level learning flow

🛠️ Functional Highlights

Designed and developed a PHP-based skill assessment and learning recommendation system that guides users in selecting appropriate technologies based on quiz performance and user inputs.

Implemented a rule-based scoring mechanism to classify users into multiple proficiency levels using predefined thresholds and logic.

Developed dynamic MCQ quiz modules with automated evaluation and real-time score analysis.

Built a content recommendation workflow that suggests free and paid learning resources based on user scores and selected technologies.

Implemented technology categorization and sorting logic to organize courses by reviews, thumbnails, tags, and difficulty levels.

Designed secure user authentication and session management using PHP for login, registration, and personalized user journeys.

Integrated a multi-level navigation flow enabling smooth progression from technology selection to assessment and learning recommendations.

🧰 Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: PHP

Database: MySQL

Tools: XAMPP / Apache
